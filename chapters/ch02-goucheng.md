# Chapter 2: 构成

## Core Idea

干部构成不是一张静态人口表，而是制度与地方历史的沉淀：级别决定职位稀缺度，家庭出身反映录用渠道的开放程度，性别显示权力代表性的漏损，年龄和学历体现干部政策，籍贯分布则同时受到交流回避、教育传统与关系网络影响。作者的统计描述可支持机制假说，但不能单独证明个人能力或具体因果。

## Frameworks Introduced

- **四级金字塔**：副科级、正科级、副处级、正处级逐层收窄。2009年中县分别有680、280、40、5人，共1013人。
  - When to use：判断某次晋升跨越了怎样的稀缺性门槛，或比较实职、非领导职务和不同管理序列时。
  - How：先分级别，再分领导／非领导职务，最后区分县管、市管和垂直管理；不能把同级职位视为等权等势。
- **精英循环与精英再生**：前者指新精英替代旧精英，后者指新精英来自旧精英家庭。作者据157名正科级一把手以上干部的家庭出身，判断二者并存而以前者为主；但他也指出，许多“农民、工人、教师家庭”实际来自各自群体中的精英家庭。
  - When to use：评估录用渠道究竟扩大流动，还是复制既有优势时。
- **权力尖端缺损**：引自相关研究，指女性越接近高层、正职和实权岗位，比例越低。中县副科级以上女性占11%，正科级一把手和县领导女性均约6%。
  - When to use：不能只看女性进入总量，还要沿级别、正副职和岗位资源继续追踪。
- **年龄规范的梯次结构**：年龄政策通过任职上限、班子梯次和“初职年龄”塑造晋升窗口。作者把较早进入县领导或乡镇正职者视为“晋升锦标赛的优胜者”。
  - When to use：解释同等现职者为何剩余晋升空间不同；同时检查年龄硬门槛带来的阶段性老化、动力下降与造假激励。
- **“中专一代”与学历跃进**：1978—1999年包分配的师范、中专提前吸收大量县域学习精英；其后在职学历大幅上升，但证书、知识和能力不必然同步。
  - When to use：分析教育代际时必须拆分第一学历、在职学历、专业和毕业年代，不能只看最高学历。
- **精英集群**：作者对政治精英在特定地域集中出现的命名。
  - When to use：某些乡镇或地区持续高比例产出干部时。
  - How：依次检验人口基数、交通与商业史、学校供给和重教传统、政治榜样、关系网络及优势累积；地域聚集只是待解释现象，不等于关系提拔的证据。

## Key Concepts

- **县管／市管／垂直管理**：分别对应县委、市委和上级条条部门的人事管理权限。
- **实职／非领导职务**：同级别内的权力和责任并不相同。
- **家庭代际上升流动**：作者称32名县领导均实现了相对父辈的地位上升。
- **纺锤形年龄结构**：县级党政班子以中间年龄段为主、两头较少。
- **初职年龄**：第一次进入某一层级领导职位的年龄，不是当前年龄。
- **第一学历／在职学历**：前者更接近入职前人力资本，后者也受资格门槛与晋升动机影响。
- **学历干部“逆淘汰”**：作者记录的本地说法，指部分第一学历本科者在县乡适应和晋升上不及早期中专生；这是现象判断，不是学历无用论。
- **交流回避／异地为官**：县乡关键正职原则上避开出生地、成长地或原籍任职。

## Mental Models

- **把人口特征当制度沉积层**：不同年龄段的家庭、教育和入职结构，反映的是不同年代的政策入口。
- **用“漏斗”看代表性**：入口比例正常而高层比例骤降，问题可能发生在培养、岗位分配或晋升阶段。
- **用“资格门槛—真实能力”双轴看学历**：文凭可作入场券，却不能替代专业与实践能力。
- **用反馈环看精英集群**：教育先产生干部，干部又形成榜样、信息和支持，可能继续强化地域优势。

## Anti-patterns

- **把家庭类别等同阶层位置**：同属“农民家庭”，村干部家庭与普通农户拥有的资源可能不同。
- **把访谈中的性别刻板印象当因果结论**：本章呈现多方说法，其中一些是偏见本身的证据，而非女性能力的证据。
- **唯年龄或唯学历**：硬指标便于执行，也可能被策略性利用，并遮蔽业绩、能力与专业适配。
- **由地域集中直接推断派系**：精英集群还可能由教育、交通、人口或历史造成，需额外网络证据。
- **忽略分母与职位性质**：比较比例时必须说明样本年份、层级、实职与非领导职务。
- **把2009年的中县阈值当永久规则**：年龄、学历和交流政策会随时期与地区变化。

## Worked Example

把本章数据做成一张“构成诊断卡”，可以避免只报比例：

| 观察层 | 中县证据 | 作者的解释 | 必须保留的边界 |
|---|---|---|---|
| 层级 | 680副科、280正科、40副处、5正处 | 四级金字塔，越往上职位越稀缺 | 同级实职与非领导职务不可等同 |
| 出身 | 157名正科级一把手以上：农民62%、干部24%、工人9%、教师5% | 录用体系较开放，精英循环为主 | 多个家庭属于各类别中的地方精英 |
| 性别 | 1013人中女性11%；高层／一把手约6% | “权力尖端缺损” | 不能从比例反推个人能力差异 |
| 教育 | 32名县领导第一学历约68%为高中或中专；在职学历本科、研究生合计约68% | “中专一代”与学历跃进并存 | 证书层级、教学质量和专业能力要分开 |
| 地域 | 125名正科级一把手中102名为中县人；若干沿河、教育较早地区集中产出干部 | “精英集群”及路径依赖 | 聚集机制需教育史、人口与网络资料互证 |

这张卡的重点不是给群体贴标签，而是把“事实—解释—证据边界”同时保留。

## Key Takeaways

1. 先按级别、职位性质和管理权限分层，再讨论干部群体。
2. 家庭出身统计既显示流动，也可能遮蔽同一类别内部的资源差异。
3. 女性代表性要沿权力层级追踪，不能只看总人数。
4. 年龄和学历是制度化筛选工具，也会制造悬崖效应和策略适应。
5. “精英集群”应作为多因素解释框架，而非关系论的捷径。
6. 本章是2009年前后单县横截面与部分历史序列，应用时要重新核验时点和范围。
