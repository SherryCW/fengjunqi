# Chapter 6: 政绩

## Core Idea

改革开放后，目标逐级分解、年度考核排名和以晋升为核心的激励，把县乡干部组织进“有为才有位”的政绩竞赛。中县材料表明，政绩对晋升具有基础作用，却从来不是单一 GDP 函数：综合目标、乡镇的既有实力、绝对与相对绩效、上级中心任务及政治忠诚共同决定何种成绩被看见；同一机制既能动员发展，也能系统性制造假政绩。

## Frameworks Introduced

- **政绩型干部体制**：通过任务分解、目标考核、锦标赛排名、奖优惩汰、检查观摩和督察来治理干部，以政治晋升为最强激励，并辅以财政奖励和荣誉。分析时依次追踪“上级任务→本级指标及权重→执行行为→考核排名→奖惩与晋升→外部后果”。它能集中动员；失败模式是考核压力压倒地方知识、长期成本与纠错。
- **政绩同构**：省向市、市向县、县向乡镇、乡镇向村逐级下达相似目标，一项任务一旦纳入考核，各级便“一荣俱荣、一损俱损”。使用时比较相邻层级的指标、权重和否决项。该机制解释了统一行动的国家能力，也解释了为何政绩工程、债务和信息失真可能同步扩散。
- **综合绩效判断**：作者将乡镇综合目标排名与 GDP、财政收入及其增速比对，发现并非一一对应；其结论是综合指标比单项经济指标、政治经济综合实力比纯经济实力更能解释晋升，并应以绝对绩效为基础兼顾相对绩效。使用时同时看总量、增速、综合考核和地方起点，避免以一项排名替代治理表现。
- **双强晋升模式**：强党委书记先在一般乡镇被识别，再流向重点乡镇，继而获得县级晋升，形成“强干部＋强乡镇”的优势累积。它提高精英乡镇效率并强化激励；失败模式是弱乡镇难获强干部、弱干部预期晋升无望，落后由此自我锁定。
- **忠诚—政绩激励机制**：政绩必须围绕上级确认的中心任务，并与服从、政治忠诚结合，才容易转化为晋升资本。该框架描述“什么会被组织认可”，不等于作者赞成以服从取代实事求是。
- **真政绩—假政绩判别**：真政绩从实际出发、因地制宜、稳健推进，重视经验和技术累积；假政绩多呈运动型、命令型、急躁冒进、一刀切、行政强推、瞎指挥与“逼民致富”。判别重点不是口号或短期数据，而是机制、可持续性、债务及群众成本。

## Key Concepts

- **中心任务**：一把手依据上级政策与本地判断确立、并通过考核权重让全县干部围绕其行动的优先事项。
- **行政逐级发包制**：上级把任务和责任逐级交给下级，塑造基层“干什么、怎么干”。
- **一票否决**：某些事项一旦不达标，即取消综合评优或相关资格；中县先后用于计划生育、农民负担和社会综合治理等领域。
- **绝对绩效**：GDP、财政收入等总量所呈现的实力；**相对绩效**是增长率或相对进步。
- **政绩工程**：优先服务考核、观摩和领导可见度，却缺乏真实产出或留下长期负担的项目。
- **一把手经济**：地方中心任务与发展方式强烈受主要领导理念影响的经验现象。
- **精英乡镇集团**：经济或政治地位较强、持续吸收强书记并输出县领导的一组乡镇。

## Mental Models

- **用“指标传导链”诊断行为**：哪里分值上升、哪里设置否决，干部资源就向哪里集中；先看考核表，再解释行动。
- **用“四账法”验政绩**：同时核对产出账、财政债务账、群众负担账和长期能力账，四账不能相互替代。
- **用“起点—变化—结果”评价弱乡镇**：只看总量会奖励先天强者，只看增速又可能放大小基数；需把起点和综合结果并置。
- **用反馈环看双强**：强乡镇提高干部出成绩与被看见的概率，晋升后又吸引更强继任者；要检验制度是否为弱乡镇提供逆转入口。

## Anti-patterns

- **唯 GDP 或唯增速**：单项经济排名与综合考核、晋升只有相对匹配，不能单独作为用人依据。
- **把完成上级指标等同于真政绩**：指标可能脱离地方资源禀赋，完成方式也可能转嫁成本。
- **运动式复制外地经验**：没有技术、市场和治理能力仍行政上项目，易形成空园区、旧设备、债务和农民负担。
- **政府直接替代市场主体**：县乡政府亲自投资或强迫群众致富，会弱化风险约束；作者主张政府重在服务和引导。
- **用晋升结果倒证政策正确**：干部获提拔只说明成绩被当时组织认可，不证明项目长期有效。
- **把假政绩归咎于单个人**：逐级压力、集体决策、信息失真、转型试错和滞后纠错共同参与结果形成。

## Worked Example

邵祝道任西城乡党委书记后，从土地少、靠近县城和已有棉纺基础出发，把工业化作为方向，却没有仿照当时普遍做法由乡镇直接投资办企业。他以中县第四棉纺厂积累的技术和人员为支点，在土地、电力等方面为民营棉纺企业提供便利；南原村及周边逐步形成产业集群。县里中心任务后来转向高效农业时，他保留必要的农业观摩点，但主要资源仍投向适合本地的棉纺产业。到 2002 年其晋升副县长时，西城主要指标已居前；研究截至 2009 年时，作者称其为全县唯一没有乡镇债务且经济实力较强的乡镇。这个案例与“圈院子、上设备、村村冒烟”的行政办厂形成对照：前者利用既有能力、让民营主体承担经营风险并持续积累技术，后者常为观摩短期开机，最终把亏损转为乡村债务和群众负担。

## Key Takeaways

1. 解释晋升，要把政绩放进综合考核、中心任务、乡镇实力和组织认可中，而不是建立单指标公式。
2. 政绩同构具有双刃性：同一传导能力既能完成重大任务，也能成规模地放大错误。
3. 双强模式揭示干部质量与地区资源的内生匹配，同时提示弱乡镇的结构性不公平。
4. 真伪政绩应以后果和生成机制判断，不以短期数据、现场观摩或干部是否升迁判断。
5. 本章结论源自 1987—2008 年中县材料，相关匹配比例是地方样本证据，不是跨地区定律。
