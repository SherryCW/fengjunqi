# Chapter 7: 关系

## Core Idea

关系不是正式制度之外的残余，而是中县政治运行中的另一套连接机制：它能传递信息、协调行动，也会把公共机会转化为家族优势、利益链和拉票竞争。解释干部晋升时，不能把关系当作唯一原因，也不能只看正式文件；应同时考察政绩、能力、领导推荐、群众基础、机遇、资历和关系如何共同作用。

## Frameworks Introduced

- **政治家族**：以血缘和姻缘为基础、在干部体系中持续产生成员的家族网络。作者将产生五名以上副科级干部者称为“大家族”，二至四名者称为“小家族”。
  - **何时使用**：判断干部机会是否存在代际传递、核心部门聚集和路径依赖。
  - **如何分析**：绘制亲属谱系，再标注教育与入伍机会、初职单位、关键岗位和代际流动；区分家庭培养、合法教育优势与违规照顾，不能仅凭亲属关系推定不当行为。
  - **为何形成/失效**：教育和录用优势、熟人圈互助、家庭政治社会化促成家族扩张；计划生育、干部交流以及子女通过高等教育转向大城市就业，又削弱其县域再生产。

- **关系网**：由血亲、姻亲、干亲、同乡、同事、同学、战友等纽带连接而成。血亲是自然纽带，其他关系需要持续交往和互惠来维持。
  - **何时使用**：解释信息为何沿特定路径流动、某些人为何能跨机构获得支持，以及监督为何可能受阻。
  - **如何分析**：标记关系强度、连接人、所处权力节点、资源流向与利益冲突；重点识别多种关系叠加后的网络位置，而非罗列“认识谁”。
  - **失效模式**：把正常社会交往等同于腐败，或反过来把利益交换包装成人情，都会遮蔽真正的合规边界。

- **“下推上拉”模式**：作者对仕途关系运作的概括。“下推”指群众基础、考核表现和单位领导推荐；“上拉”指更高层领导对县级主要领导施加影响，随后再进入县内决策。
  - **何时使用**：重建一次晋升的多层动力，而不是用单一政绩或单一关系解释结果。
  - **如何分析**：依时间顺序核对基层评价、资格与政绩、推荐来源、酝酿过程和正式任命，检查哪一环改变了候选排序。
  - **边界**：这是制度诊断模型，不是关系运作指南。若“上拉”替代资格、民意或程序，它就是选择机制被俘获的风险信号。

- **拉票网与多重博弈**：民主推荐原本要以多数选择淘汰明显不合格者，却也让选票成为关系动员对象。早期拉票者获益且未受惩罚，会引发模仿；普遍化后，不拉票又被误读为“不求进步”，形成自我强化。
  - **何时使用**：评估一项参与式制度在行动者适应之后，是否仍实现原目标。
  - **如何分析**：比较制度目的、实际行为、选择结果和外部成本；关注公款消耗、财政债务、健康损害、腐败风险及“公关型干部”胜出等后果。
  - **失败模式**：仅扩大投票范围未必能消除拉票，也可能把动员成本同步放大。

- **关系与干部仕途的双环模型**：内环是干部政策、资格、考察、常委会和任命文件等正式规则；外环是非正式关系运作，围绕内环旋转。书记办公会是外环与内环的连接环节，县委常委会则是正式效力形成的核心程序。
  - **何时使用**：正式材料显示程序完备，但结果似乎在会议前已基本确定时。
  - **如何分析**：把“事前酝酿—名单形成—正式审议—文件生效”拆开，分别追踪证据、参与者和可否复核性。
  - **为何重要**：非正式协调最终须取得正式形式；只核验任命文件，会把合法形式误当成完整因果过程。

## Key Concepts

- **关系**：对干部仕途尤其是晋升有用的社会资源；其作用可能是信息与协作，也可能是不当偏袒。
- **关系本位**：以人际纽带而非抽象规则组织行动的社会文化倾向，是作者解释关系持续性的背景之一。
- **过度竞争**：干部数量与上升岗位高度不对称，使微小优势、关系动员和资金投入被放大。
- **关系正反馈**：关系确实改变过结果，成功案例遂诱发更多人投入关系运作。
- **核心圈**：围绕候选人形成的密切支持网络；研究时用于识别协调节点，不应用于设计拉票。
- **正式程序**：资格、推荐、考察、集体决策和任命等可见环节，构成双环模型的内环。
- **问题家族化**：家族成员向核心部门聚集并形成利益链后，公共决策可能受私人网络影响。

## Mental Models

- **用“双环”看制度落地**：规则说明事情应当怎样发生，关系网络解释事情可能怎样被预先塑形；两者必须同时验证。
- **用“网络位置”代替“单条关系”**：一条弱联系未必有效，多条跨层级联系叠加才可能改变资源和信息流。
- **用“多因素合力”解释晋升**：关系通常是催化剂，能力与政绩常是基础；个别关系突破资格底线的案例，应作为制度失灵而非一般规律。
- **用“反馈回路”评估票决制**：若违规收益可见、惩罚不可见，个体理性会汇成集体失序。

## Anti-patterns

- **关系决定论**：把每次晋升都归因于后台，会抹去能力、政绩、资格和偶然性，也超过作者证据所能支持的范围。
- **文件即事实全貌**：正式任命只能证明最终结果合法化，不能证明前置酝酿没有偏差。
- **亲属即违规**：谱系揭示风险暴露面，不自动构成利益输送证据；判断必须落到具体事项、利益和程序。
- **把拉票材料写成操作手册**：请客、送礼和关系动员属于本章分析的制度风险，不应被复现为影响选票的方法。
- **只谈文化、不谈激励**：人情传统不足以解释关系扩张；岗位稀缺、票决激励、执行不力和成功示范同样关键。

## Worked Example

作者以中县民主推荐的运行重构了一条制度异化链：制度先以投票增加民意基础；部分有晋升希望的干部随后围绕既有关系争取支持；率先动员者获得更好结果而未被有效追责，其他候选人开始模仿；当动员普遍化，不参与者又被视为没有晋升意愿；最终，选票不再只表达工作评价，还混入人情、资源投入和互惠压力。结果既可能扭曲候选排序，也把成本外溢到单位财政、干部健康与纪律风险。

这个例子提示：审计民主推荐不能只检查“是否投过票”，还应检查候选形成是否独立、投票者是否受利益影响、异常支出和利益冲突是否可追溯、违规收益是否被及时纠正。作者同时提醒，取消投票会退回“少数人选少数人”，单纯扩大范围又可能扩大动员成本；真正难点是让参与机制与可执行的反拉票约束同步存在。

## Key Takeaways

1. 先重建完整晋升链条，再判断关系究竟是信息渠道、催化因素还是越过资格底线的决定力量。
2. 政治家族研究应从谱系进入机会结构：教育、初职、关键岗位和代际迁移比姓氏本身更有解释力。
3. 正式制度会改变行动者策略；评价制度必须观察实施后的适应、博弈与外部成本。
4. 民主推荐既增加参与，也可能制造关系动员；程序存在不等于选择未被影响。
5. 双环模型最适合解释“前置协调、正式确认”的过程，但不能把所有非正式沟通都预设为腐败。
6. 合规治理的重点是利益冲突、透明度、可复核性与违规后果，而不是学习如何经营关系。
