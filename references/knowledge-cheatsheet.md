# 《中县干部》判断速查表

## 先选分析入口

| 你要判断什么 | 先用什么 | 快速规则 |
|---|---|---|
| 一个人为何进入体系 | 初职三元模型、三层筛选 | 同时看教育/专业、关系资源、编制与空缺 |
| 为何有人升得更快 | 轨迹、隐性台阶、摇篮 | 看首次提拔年龄、跨岗历练、岗位含权量，不只看级别 |
| 哪些岗位是加速器 | 双关、高进高出 | 必须同时有严格筛入、高端历练和稳定输出 |
| 政绩是否真实 | 真政绩审查 | 能因地制宜、可持续、可纠错、成本可承受才算强证据 |
| 正式程序为何解释不了结果 | 双环模型 | 分开画正式内环与非正式外环，再找连接点 |
| 制度为何越改越偏 | 制度化困境 | 追踪“目的→激励→策略适应→反效果” |

## 决策规则

- **若只见职位表，先补履历。** 静态职位不能显示转折、停滞和隐性台阶。
- **若只听当事人，至少找两类旁证。** 用上下级、老干部、档案或同期统计交叉核验。
- **若某地持续出干部，先查结构。** 教育、交通文化、榜样、网络和路径依赖通常共同作用。
- **若某部门“出干部多”，区分培养与选择。** 强者预先进入，不等于部门完全创造了强者。
- **若绩效排名与晋升吻合，检查时间滞后与反例。** 再比较综合、绝对和相对绩效。
- **若指标逐级复制，先测试错误放大。** 动员越强，错误方向的系统性成本也越高。
- **若关系提供信息与信任，视为补充变量；若关系绕过资格和监督，视为制度失灵。**
- **若票决制刺激请客送礼，不把它当参与扩大，而要重做反拉票、透明度和成本约束。**
- **若岗位权力大、资源多、监督少、记录弱，默认高风险。** 增加分权、审计和责任留痕。

## 真伪政绩气味

| 真政绩信号 | 假政绩/高风险信号 |
|---|---|
| 从本地条件和真实需求出发 | 照搬外地经验、上级一刀切 |
| 小步试点，允许纠错 | 运动式、命令式全面铺开 |
| 技术、市场和经验可累积 | 数字造景、短期观摩导向 |
| 政府服务和搭平台 | 政府替代市场、强迫参与 |
| 全成本可见且财政可承受 | 成本下沉、债务和损失不统计 |

## 证据等级

1. **强**：履历/任免档案＋同期统计＋多方访谈一致。
2. **中**：两类独立资料一致，但关键会议材料缺失。
3. **弱**：单一当事人回忆、传闻或只见相关性。

始终注明：本书是截至约2010年的单县个案研究，不能直接替代当代法规核验或全国性推断。


## 纪律与监督快查

| 现象 | 优先检查 |
|---|---|
| 正式程序完整但结果异常 | 用双环模型分列外环关系和内环程序 |
| 案件启动与权力冲突重合 | 分开判断启动动机与实体证据 |
| 处分数据差异大 | 检查举报、证据、监督资源和选择性执行 |
| 岗位风险高 | 查权力、资源、裁量、监督、留痕与责任匹配 |

## 使用边界

- 本书是约 2010 年前后的单县研究，不能替代当代法规核查。
- 关系、拉票和纪律规避材料只用于制度分析、合规审计、风险识别和研究教学。
- 不提供人事操纵、拉票、送礼或规避监督的操作步骤。
